# Wordlists

## `eff_large.txt`

7776 английских слов для генерации парольных фраз (diceware).

- Источник: <https://www.eff.org/files/2016/07/18/eff_large_wordlist.txt>
- Автор: Electronic Frontier Foundation, проект «Deep Dive: EFF's New Wordlists for Random Passphrases»
  (<https://www.eff.org/deeplinks/2016/07/new-wordlists-random-passphrases>).
- Лицензия: Creative Commons Attribution 3.0 US (<https://creativecommons.org/licenses/by/3.0/us/>).
- Изменения: удалены колонки с номерами кубиков (файл содержит только слова), порядок сохранён.
  Слова не редактировались; 4 слова с дефисом (`drop-down`, `felt-tip`, `t-shirt`, `yo-yo`) сохранены как в источнике.

7776 = 6^5 слов, то есть 12.925 бита энтропии на слово.
