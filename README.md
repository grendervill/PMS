# PMS

Локальный менеджер паролей, TOTP-секретов и SSH-ключей. Хранилище — переносимая
зашифрованная папка, без сервера и телеметрии.

## Что уже работает

- Создание переносимого хранилища в выбранной папке и разблокировка
  пароль-фразой, ключ-файлом (OpenSSH / PEM / PKCS#8), пароль-фразой вместе
  с ключ-файлом или Touch ID. SSH-ключ можно использовать как отдельный
  альтернативный способ входа, указав его парольную фразу.
- Настройка «Всегда разблокировать при помощи биометрии»: до 5 попыток,
  затем обычный ввод пароль-фразы; ключ хранится в macOS Keychain.
- Argon2id + XChaCha20-Poly1305 или AES-256-GCM; параметры KDF хранятся
  в заголовке и не перезатираются.
- Записи: имя, логин, пароль, несколько URL, комментарий; скрытие/показ и копирование.
- TOTP-секреты: `otpauth://` или base32, живые коды с таймером, общий экран TOTP,
  сканирование и показ QR.
- Передача карточки PMS по QR (без вложений и SSH), с паролем или без.
- Импорт Bitwarden, 1Password, KeePass, Kaspersky, браузерных CSV и generic CSV;
  экспорт/импорт зашифрованного `.pmsvault`.
- SSH-ключи: ed25519, RSA 2048/3072/4096, ECDSA P-256/P-384/P-521; OpenSSH,
  PEM/PKCS#8, установка в `~/.ssh` с правами 600/700 и проверкой, привязка к записям.
- Зашифрованные вложения: фото, PDF, текст и другие файлы; превью, скачивание.
- История логинов и паролей; повторное использование старого пароля
  блокируется.
- Генераторы логина и пароля с длиной, наборами символов, своими символами
  и пересозданием.
- Предупреждения о слабых и повторяющихся паролях; экран «Проверка».
- Автоблокировка при бездействии: 10/20/30 секунд, 2/5/10/20/30/60 минут,
  до завершения программы или без блокировки; зашифрованные черновики
  несохранённых форм.
- Бэкапы хранилища: авто по расписанию 1/7/30 дней, хранение 1/7/30 дней,
  ручное создание; самый свежий бэкап не удаляется никогда.
- Передача полной копии хранилища между устройствами PMS по локальной сети:
  поиск через Bonjour и UDP-broadcast, ручной IP, шестизначный код, замена текущего хранилища с бэкапом
  или приём в новую папку.
- Атомарная запись vault-файла, права 600/700 на macOS/Linux.
- Три значка приложения с выбором в настройках; по умолчанию — зелёный замок.
- Сборка macOS Apple Silicon: `.app` и `.dmg`.
- Android: Tauri-приложение на том же React UI; SAF-хранилище, создание/вход,
  записи, вложения, бэкапы, QR-камера, импорт/экспорт `.pmsvault`, SSH-экспорт,
  Android-биометрия и мобильная навигация с разделом «Ещё».

## Чего пока нет

Это рабочий срез для macOS и Android. На Android уже работают SAF-хранилище,
основные экраны, вложения, QR-камера, бэкапы, импорт/экспорт и биометрия;
осталось проверить на реальном устройстве обмен по локальной сети, фон/back
и провайдеры SAF. Полная матрица функций и ограничения — в
`docs/superpowers/specs/2026-10-21-android-parity-design.md`.
Раздел обмена пока **не доделан**: автоматическое обнаружение устройств
ненадёжно, поэтому его нужно считать экспериментальным до отдельного этапа.
Bluetooth-обнаружение также требует отдельного CoreBluetooth-слоя.
Windows/Linux и полировка — после Android. Дизайн и планы лежат в
`docs/superpowers/`.

## Разработка

```bash
pnpm install
pnpm tauri dev
```

Проверки:

```bash
pnpm typecheck
pnpm test          # 114 frontend-тестов
pnpm test:e2e      # 16 Playwright-сценариев, мок Tauri IPC
cargo test --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings

# Android debug APK (нужны Android SDK/NDK и rustup targets)
export ANDROID_HOME="$HOME/Library/Android/sdk"
export NDK_HOME="$ANDROID_HOME/ndk/28.2.13676358"
pnpm tauri android build --debug -t aarch64 --apk
pnpm tauri build   # macOS ARM: .app + .dmg
```

Тестовый vault для ручной проверки можно создать через UI; он не входит в репозиторий.

## Безопасность

Никаких секретов в логах. Пароль-фраза и ключ-файл не хранятся. Потеря всех
способов входа означает потерю данных — восстановления нет.
