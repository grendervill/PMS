# PMS

Локальный менеджер паролей, TOTP-секретов и SSH-ключей. Хранилище — переносимая
зашифрованная папка, без сервера и телеметрии.

## Что уже работает

- Создание переносимого хранилища в выбранной папке и разблокировка
  пароль-фразой или ключ-файлом (OpenSSH / PEM / PKCS#8).
- Argon2id + XChaCha20-Poly1305 или AES-256-GCM; параметры KDF хранятся
  в заголовке и не перезатираются.
- Записи: имя, логин, пароль, URL, комментарий; скрытие/показ и копирование.
- TOTP-секреты: `otpauth://` или base32, живые коды с таймером, общий экран TOTP.
- Зашифрованные вложения: фото, PDF, текст и другие файлы; превью, скачивание.
- История логинов и паролей; повторное использование старого пароля
  блокируется.
- Генераторы логина и пароля с длиной, наборами символов, своими символами
  и пересозданием.
- Предупреждения о слабых и повторяющихся паролях; экран «Проверка».
- Автоблокировка и зашифрованные черновики несохранённых форм.
- Атомарная запись vault-файла, права 600/700 на macOS/Linux.
- Сборка macOS Apple Silicon: `.app` и `.dmg`.

## Чего пока нет

Это первый срез. В следующих планах: SSH-ключи, Android SAF, экспорт/импорт
`.pmsvault`, резервные копии и проверка конфликтов, экран настроек, favicon
сайтов, финальная полировка Windows/Linux. Дизайн и планы лежат в
`docs/superpowers/`.

## Разработка

```bash
pnpm install
pnpm tauri dev
```

Проверки:

```bash
pnpm typecheck
pnpm test          # 82 frontend-теста
pnpm test:e2e      # 4 Playwright-сценария, мок Tauri IPC
cargo test --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
pnpm tauri build   # macOS ARM: .app + .dmg
```

Тестовый vault для ручной проверки можно создать через UI; он не входит в репозиторий.

## Безопасность

Никаких секретов в логах. Пароль-фраза и ключ-файл не хранятся. Потеря всех
способов входа означает потерю данных — восстановления нет.
