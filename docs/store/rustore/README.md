# Скриншоты для магазина приложений

Три скриншота для карточки приложения в RuStore: `01-entries.png`, `02-entry.png`,
`03-generator.png`.

Параметры (под требования RuStore к скриншотам телефона):

| Параметр | Значение |
|---|---|
| Формат | PNG (без потерь), sRGB |
| Размер | 1080 × 1920 px (портрет, 9:16) |
| Содержимое | только интерфейс приложения: без рамок устройства, без статус-бара, без водяных знаков и сторонних надписей |
| Данные | демонстрационные: «Кингуру», «Почта», «Ипотека», «Домашний Wi-Fi», «Рабочий сервер» |

Что на скриншотах:

1. **Записи** — список с карточками в продвинутом режиме: имя, адрес сайта, логин,
закрытый пароль, комментарий, монограммы.
2. **Карточка записи** — логин, пароль, сайт, живой TOTP-код с прогрессом, комментарий.
3. **Генератор** — сгенерированный пароль, индикатор стойкости, длина и наборы символов.

## Как перегенерировать

Скриншоты снимаются с реального интерфейса (Playwright + мок Tauri IPC), поэтому после
редизайна их достаточно пересобрать:

```bash
SCREENSHOTS=1 npx playwright test tests/e2e/store-screenshots.spec.ts
```

Файлы перезапишутся в этой папке. Без переменной `SCREENSHOTS` тест пропускается, так что
обычный `npx playwright test` ничего не трогает.

Если магазину понадобится другой размер (например, 1440 × 2560 или 20:9), поменяй
`viewport` и `deviceScaleFactor` в `test.use(...)` — картинки будут того же вида.
