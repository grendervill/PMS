# Android: серверный режим на устройстве

Дата: 2026-11-19
Ветка: `feat/android-sync` (план 5)

## Что сделано

- **Биометрический блок версии 2** (`core/biometric_payload.rs`): `{ключ сейфа, семя
  identity-ключа}` с версионным байтом. Версия 1 (только ключ) читается по-прежнему;
  мусорные данные отвергаются, а не становятся ключом. macOS и Android используют один
  формат.
- **Вход в сервер по биометрии**: семя, прочитанное при разблокировке, позволяет поднять
  серверную сессию без пароль-фразы (`remote_login_biometric`). Блокировка сейфа
  обнуляет семя — и в реестре сессий, и в состоянии приложения.
- **Доверие по первому подключению**: `remote_probe` сначала снимает отпечаток ключа,
  затем проверяет тот же сервер уже с пином. Без этого к серверу со своим сертификатом
  подключиться было нельзя вообще (нашёл на эмуляторе).
- **Пустой серверный аккаунт** больше не показывается ошибкой: приложение открывает
  экран приветствия и предлагает создать сейф.
- **Создание сейфа в серверном режиме**: визард пропускает шаг выбора папки, пишет в кэш
  профиля и сразу отправляет сейф на сервер.
- **Жизненный цикл**: таймер синхронизации останавливается в фоне и срабатывает при
  возврате в приложение.

## Проверка на эмуляторе (Android 12, arm64, API 31)

Собран подписанный release APK (35 МБ; debug-сборка на 634 МБ не влезала в раздел данных
эмулятора), установлен через `adb`, запущен:

1. экран выбора режима — верстка на телефоне держится, кнопки нажимаются;
2. «Подключить сервер» → адрес `https://192.168.1.233:8443` → проверка прошла,
   показан отпечаток `8736A48A AA16FB0A FFC F766F 41EF82B4 F2E99381 F9851B72 0FAEDAD9 24E706D8`,
   совпадает с `openssl` на сервере;
3. регистрация аккаунта — на сервере появился аккаунт, приложение вернулось в режим
   сервера;
4. пустой аккаунт открывается приветствием без ошибки;
5. визард создания сейфа: шаг «Сервер» уже пройден, спрашивается только защита.

Скриншоты: `test-results/android-{mode-chooser,server-form,server-check,remote-empty,wizard,wizard-6,release-start}.png`.

## Что осталось проверить на живом устройстве

- создание сейфа с отправкой на сервер и правка записи с пушем (первый шаг прошёл,
  дальше — по шагам из runbook);
- биометрия: вход по отпечатку в серверном режиме (на эмуляторе отпечаток не настроен);
- работа в фоне: уход в фон и возврат.

## Замечание по сборке

`cargo` из Homebrew не знает Android-таргетов: сборку надо запускать с
`PATH="$HOME/.cargo/bin:$PATH"`. Release APK без подписи не ставится — подписывать
`apksigner` дебажным ключом (для тестов) или релизным (для раздачи).
