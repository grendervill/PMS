# PMS — план 3: SSH-ключи

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Добавить раздел SSH: генерация ключей (ed25519, RSA, ECDSA), форматы OpenSSH/PEM/PKCS#8, установка в `~/.ssh` с правами 600/700, проверка/починка прав и привязка ключей к записям.

**Architecture:** Rust генерирует и конвертирует ключи; приватные ключи хранятся в зашифрованном `VaultData.sshKeys` в OpenSSH-формате. Установка — отдельная явная команда, которая пишет файлы на диск и выставляет права. React — раздел SSH, редактор, детали и привязка в записях.

**Tech Stack:** Rust `ssh-key`, `rsa`, `p256/p384/p521`, `ed25519-dalek`, `atomicwrites`, `libc`; React, Tauri.

**Spec:** `docs/superpowers/specs/2026-10-20-pms-design.md`

## Global Constraints

- Ключи: ed25519, RSA 2048/3072/4096, ECDSA P-256/P-384/P-521.
- Форматы: OpenSSH private/public, PEM PKCS#1 (RSA), SEC1 (ECDSA), PKCS#8; публичный — OpenSSH.
- Приватный ключ хранится зашифрованным в vault; на диск попадает только по явной команде установки/экспорта.
- Права Unix: каталог 700, private 600, public 644. Не запускать sudo; при чужом владельце показать команду.
- Windows: ACL через `icacls`; Android — SAF (следующий план).
- Парольная фраза SSH-ключа опциональна; если задана, хранится в зашифрованном vault только по выбору пользователя.
- Имя файла: только `[A-Za-z0-9._-]`, без разделителей пути.
- Не логировать приватные ключи и парольные фразы.
- TDD; каждый task завершается тестами.

## Review Focus

- Сгенерированный ключ валиден и fingerprint совпадает.
- Приватный ключ с парольной фразой расшифровывается только с ней.
- Установка не перезаписывает чужие файлы без подтверждения; права 600/700.
- Ключ нельзя установить по пути с `../`.
- Связь ключа с записью сохраняется после lock/unlock.
- Чужой владелец файла не приводит к молчаливому chmod; показывается команда.
