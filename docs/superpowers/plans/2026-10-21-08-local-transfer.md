# PMS — план 8: обмен хранилищем по локальной сети

**Goal:** Передавать полную зашифрованную копию хранилища между двумя устройствами PMS в локальной сети. Получатель заранее выбирает «Заменить текущее» или «Выбрать новую папку», подтверждает передачу шестизначным кодом, а после получения открывает новое хранилище.

**Architecture:** Получатель запускает временный HTTP-сервер на случайном порту и объявляет Bonjour/mDNS-сервис `_pms._tcp.local.`. Отправитель ищет сервис, экспортирует текущую папку в `.pmsvault` и отправляет архив на сервер с кодом в заголовке. Архив уже зашифрован; дополнительного транспортного шифрования в этом срезе нет, код защищает от случайной передачи. Получатель сохраняет архив во временный файл, показывает событие `transfer://received`, после чего UI устанавливает архив и открывает хранилище.

**Tech Stack:** Tauri 2, Rust, `mdns-sd`, `tiny_http`, `local-ip-address`, `hostname`, React 19, Tailwind, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-21-biometrics-qr-import-design.md`

## Global Constraints

- Платформа: macOS Apple Silicon; протокол и команды не должны мешать Windows/Linux.
- Передаётся только `pms.vault` и `attachments/`; `backups/` не передаются.
- Пароль-фраза, ключ-файл и SSH-ключи не передаются.
- При замене текущего хранилища сначала создаётся резервная копия в `backups/`.
- Архив проверяется существующим `pms_archive::import` (манифест, SHA-256, безопасные пути).
- Временные архивы и vault-файлы получают права `600`, папки — `700` на Unix.
- UI на русском; навигация — раздел «Обмен» с вкладками «Передать на» / «Принять с».
- Bluetooth-обнаружение в этот срез не входит: macOS CoreBluetooth требует отдельного периферийного слоя; локальная сеть покрывает передачу данных.

## Review Focus

- **Код подтверждения:** показывается на принимающем устройстве, вводится на отправляющем; неверный код не даёт загрузить архив.
- **Замена:** текущий vault копируется в `backups/` до перезаписи; вложения старого vault не удаляются.
- **Сбой установки:** текущий vault не перезаписывается до успешного импорта во временную папку.
- **Сеть:** при отсутствии разрешения macOS на локальную сеть поиск возвращает пустой список, приложение не падает.
