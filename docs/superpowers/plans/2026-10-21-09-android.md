# PMS — план 9: Android parity

**Goal:** Довести Android-приложение до функционального и визуального паритета с macOS-версией на общем React UI и Rust-ядре.

**Spec:** `docs/superpowers/specs/2026-10-21-android-parity-design.md`

**Build:** `pnpm tauri android build --debug -t aarch64 --apk` (SDK/NDK/rustup targets обязательны).

## Tasks

### 1. Android target

- [x] `tauri android init --ci`, `minSdkVersion: 28`.
- [x] Rust targets `aarch64-linux-android`, `armv7-linux-androideabi`, `i686-linux-android`, `x86_64-linux-android`.
- [x] Debug APK на эмуляторе API 35 (arm64).
- [x] CAMERA/INTERNET/Wi-Fi multicast permissions, Android launcher icon.

### 2. SAF storage

- [x] `tauri-plugin-android-fs` + JS API.
- [x] Folder picker with persistable permission, opaque URI token, display name.
- [x] `readVault`/`writeVault`/attachments/backups/list.
- [x] Save-file picker for QR/SSH/export.
- [x] Import/export `.pmsvault` through app-cache staging + Rust manifest/SHA validation.
- [x] Real emulator flow: create vault, add entry, save, restart, unlock, export, import, backup.

### 3. UI

- [x] Same React views; safe-area top padding on Android.
- [x] Bottom navigation: Записи, TOTP, SSH, Настройки, Ещё.
- [x] Full-screen detail/editor, mobile modal footer stacking.
- [x] Android back button: close detail/editor/QR or go to entries; exit at root.
- [x] Три launcher-иконки через activity-alias; SSH install скрыт, форматы экспортируются.
- [ ] Visual check on a physical phone and tablet/foldable (emulator phone checked).

### 4. Platform features

- [x] QR camera via WebView `getUserMedia` + jsQR; camera permission prompt tested.
- [x] Android BiometricPrompt/Keystore cipher via `tauri-plugin-biometric`.
- [x] mDNS multicast lock for transfer discovery; Android staging for transfer send/install.
- [x] Clipboard via existing plugin.
- [x] Biometrics verified on emulator with enrolled fingerprint; real-device retest pending.
- [ ] Verify transfer between Android and macOS.
- [ ] App background lock / optional FLAG_SECURE setting.

### 5. Verification

- [x] `pnpm typecheck`, `pnpm lint`, `pnpm test` (107).
- [x] `pnpm test:e2e` (15).
- [x] Rust tests/clippy on macOS.
- [x] Android target clippy (`aarch64-linux-android`).
- [x] Emulator visual checks: welcome, create wizard, entries, detail, settings, QR camera, export/import, back.
- [ ] Release APK/AAB signing.
